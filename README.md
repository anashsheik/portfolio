# anashsheik.tech

Personal website for Anas Sheik, MSc student in Data Science at the University of Oslo.

Built with React and Vite, deployed on Vercel. The site is available in Norwegian and English (toggle in the menu, or link directly with `?lang=en`).

## Edit content

All text (both languages), projects, skills and education live in `src/content.js`. `src/App.jsx` only handles layout and styling.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```
